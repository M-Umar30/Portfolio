Businesses Board

ResourcePool · 2026 · client work

An operations platform for about 15 staff across 14 business groups. A Router hands each request to the right agent: an Overseer briefs the owner, a Planner sets the week, an Analyst answers questions, a Scribe drafts messages. An AI CEO argues with the Planner when they disagree.

  • Guardrails come from which MCP tools each agent is handed. No agent can spend, hire, message a client or delete.
  • A light model for frequent briefs, a reasoning model for judgment calls.
  • Every agent has a deterministic fallback, so the system runs end to end without an API key.

Personal project · open source
